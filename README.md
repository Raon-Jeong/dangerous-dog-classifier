# DangerDog : 애견 동반 업장 5대 맹견 자동 분류 시스템

웹캠 영상에서 강아지를 찾아, 법으로 정한 맹견 5종일 확률을 실시간으로 계산하고 화면과 경고음으로 알려주는 윈도우 프로그램입니다.
YOLO 탐지 모델과 직접 학습한 품종 분류 모델을 순서대로 연결한 2단계 구조로 만들었고, 파이썬이 없는 컴퓨터에서도 실행되는 실행파일(.exe)까지 완성했습니다.

## 4. 시스템 구조

![시스템 구조](docs/images/architecture.png)

1. **탐지** : COCO 데이터로 사전학습된 `yolo26n.pt`로 화면에서 `dog` 클래스만 찾습니다. (추가 학습 없음)
2. **잘라내기** : 탐지된 박스 부분만 잘라서 분류 모델에 넣습니다. 강아지가 여러 마리면 각각 처리합니다.
3. **분류** : 직접 학습한 `best_dog_cls.pt`가 품종별 확률을 출력합니다.
4. **맹견 확률** : 맹견 클래스들의 확률을 모두 더한 값입니다. 이 값이 기준값(0.1) 이상이면 "맹견 추정"으로 표시하고 경고음을 냅니다.

분류 모델 학습 전에 모든 학습 이미지도 같은 탐지 모델로 잘라냈습니다. 학습할 때 보는 이미지와 실제로 판정할 때 보는 이미지의 조건을 같게 만들기 위해서입니다.

자세한 내용 : [docs/03_시스템_구조.md](docs/03_시스템_구조.md)

## 5. 성능

test 데이터(학습에 쓰지 않은 15 %) 기준입니다.

| 항목 | 값 |
|:--|:--|
| 품종 분류 top-1 정확도 | [입력: 노트북 5-1 출력값] |
| 품종 분류 top-5 정확도 | [입력: 노트북 5-1 출력값] |
| 맹견 재현율 (기준값 0.1) | 164 / 168 = 97.6 % |
| 품종별 놓친 수 | 로트와일러 1장, 도사견 3장, 나머지 0장 |
| 일반견을 맹견으로 오판정 | 약 15장 |

기준값은 0.01부터 0.9까지 바꿔 가며 정밀도와 재현율을 비교한 뒤 정했습니다. 맹견을 놓치는 것이 일반견을 잘못 잡는 것보다 위험하므로 재현율을 우선했습니다.

자세한 내용 : [docs/05_성능평가.md](docs/05_성능평가.md)

## 6. 실행 방법

### 6-1. 파이썬으로 실행 (개발자용)

```
conda create -n dangerdog python=3.11 -y
conda activate dangerdog
pip install -r requirements.txt
```

모델 파일 2개를 `app` 폴더에 넣습니다. (용량 때문에 저장소에는 없습니다)

| 파일 | 설명 | 받는 곳 |
|:--|:--|:--|
| `best_dog_cls.pt` | 직접 학습한 품종 분류 모델 | [입력: 구글 드라이브 또는 GitHub Releases 링크] |
| `yolo26n.pt` | 사전학습 탐지 모델 | 첫 실행 시 Ultralytics가 자동 다운로드 |

```
cd app
python app_gui.py
```

### 6-2. 실행파일로 실행 (일반 사용자용)

[입력: DangerDog.zip 다운로드 링크]를 받아 압축을 풀고 `DangerDog.exe`를 더블클릭합니다. 파이썬 설치가 필요 없습니다.
"Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.

실행파일을 직접 만드는 방법 : [docs/실행파일_만들기_가이드.md](docs/실행파일_만들기_가이드.md)

## 10. 라이선스와 고지

- 이 프로젝트는 Ultralytics YOLO(AGPL-3.0)를 사용합니다. 코드와 학습한 모델을 재배포할 때는 AGPL-3.0 조건을 따라야 합니다.
- Stanford Dogs 데이터(ImageNet 기반)는 비상업적 연구 · 교육 목적으로만 사용했습니다.
- 판정 결과는 참고용입니다. 최종 확인은 사람이 해야 하며, 법적 판단의 근거로 사용할 수 없습니다.
